# Анализ тональности отзывов с использованием TF-IDF и логистической регрессии

Этот блокнот демонстрирует базовый процесс предварительной обработки текста, векторизации с помощью TF-IDF и классификации тональности (sentiment analysis) с использованием логистической регрессии.

## Описание шагов
1. **Подготовка данных**: Создание демонстрационного набора данных, состоящего из положительных и отрицательных отзывов о фильмах.
2. **Очистка текста**: Приведение к нижнему регистру, удаление знаков препинания, цифр и стоп-слов (при этом важные отрицания, такие как `not`, `no` и `nor`, сохраняются).
3. **Разделение данных**: Разделение выборки на обучающую и тестовую в соотношении 70/30 со стратификацией.
4. **Векторизация**: Преобразование текстовых данных в числовые признаки методом TF-IDF.
5. **Обучение модели**: Обучение модели логистической регрессии (`LogisticRegression`).
6. **Оценка качества**: Расчет метрики Accuracy, вывод отчета классификации (`classification_report`) и матрицы ошибок (`confusion_matrix`).
7. **Анализ ошибок**: Выделение примеров, на которых модель допустила ошибки, для дальнейшего улучшения алгоритма.
